# Agent Reference

This edition keeps the agents that directly support operations planning and delivery.

| Agent | Role |
|---|---|
| `gsd-project-researcher` | Research service domain and operational landscape during project or milestone setup |
| `gsd-phase-researcher` | Research implementation and operating patterns for a phase |
| `gsd-ops-researcher` | Research inputs for operational documentation |
| `gsd-research-synthesizer` | Consolidate research output |
| `gsd-planner` | Produce executable plans |
| `gsd-roadmapper` | Build phase roadmaps from requirements |
| `gsd-executor` | Execute plans |
| `gsd-plan-checker` | Verify plans before execution |
| `gsd-integration-checker` | Verify milestone-level integration and readiness |
| `gsd-verifier` | Verify phase goal achievement |
| `gsd-nyquist-auditor` | Fill validation gaps |
| `gsd-codebase-mapper` | Map brownfield systems and service surfaces |
| `gsd-debugger` | Diagnose failures and gaps |

Removed from this edition:

- UI design and UI review agents
- Developer profiling agent
