# CLI Tools

`get-shit-done/bin/gsd-tools.cjs` provides the structured utility layer used by workflows.

## High-value Commands

- `init <workflow>`
- `resolve-model <agent>`
- `phase add|insert|remove|complete`
- `roadmap analyze|get-phase|update-plan-progress`
- `state load|patch|update-progress|advance-plan`
- `verify plan-structure|phase-completeness|references|artifacts|key-links`
- `template fill ...`
- `validate consistency|health`

## Operations Extensions

- `init ops-runbook`
- `init ops-audit`

These are used by the dedicated operations documentation workflows.
