# GSD 命令参考

## 推荐流程
1. `/gsd:map-codebase`
2. `/gsd:new-project`
3. `/gsd:plan-phase <阶段>`
4. `/gsd:execute-phase <阶段>`
5. `/gsd:verify-work [阶段]`
6. `/gsd:ops-runbook`
7. `/gsd:ops-audit`
8. `/gsd:help`

默认分析内核：
- `Latency`
- `Traffic`
- `Errors`
- `Saturation`

这个裁剪版只保留核心运维流程命令。
