# GSD 命令参考

## 核心流程
1. `/gsd:map-codebase`
2. `/gsd:new-project`
3. `/gsd:autonomous`
4. `/gsd:discuss-phase <阶段>`
5. `/gsd:plan-phase <阶段>`
6. `/gsd:execute-phase <阶段>`
7. `/gsd:verify-work [阶段]`
8. `/gsd:ops-runbook`
9. `/gsd:ops-audit`

## 里程碑
- `/gsd:audit-milestone`
- `/gsd:complete-milestone`
- `/gsd:new-milestone`
- `/gsd:plan-milestone-gaps`

## 阶段工具
- `/gsd:add-phase`
- `/gsd:insert-phase`
- `/gsd:remove-phase`
- `/gsd:list-phase-assumptions`

## 运行期工具

- `/gsd:resume-work`
- `/gsd:pause-work`
- `/gsd:health`
- `/gsd:settings`
- `/gsd:set-profile`
- `/gsd:update`
