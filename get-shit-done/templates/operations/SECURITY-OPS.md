## 事故响应

### 安全事故等级

| 等级 | 定义 | 示例 | 响应团队 |
|------|------|------|----------|
| P1 - 严重 | 正在发生入侵，数据已暴露 | 勒索软件 | 完整事故响应 |
| P2 - 高 | 潜在入侵 | 可疑访问 | 安全团队 |
| P3 - 中 | 安全策略违规 | 轻微暴露 | 团队负责人 |
| P4 - 低 | 策略提醒 | 配置漂移 | 仅通知 |

### 事故响应流程

```
1. DETECT
   ├── 自动告警
   ├── 人工发现
   └── 用户报告

2. CONTAIN
   ├── 隔离受影响系统
   ├── 保全证据
   └── 防止扩散

3. ERADICATE
   ├── 清除威胁
   ├── 修补漏洞
   └── 加固系统

4. RECOVER
   ├── 恢复服务
   ├── 校验完整性
   └── 监控是否复发

5. POST-INCIDENT
   ├── 记录发现
   ├── 根因分析
   └── 落实改进
```
